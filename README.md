# Basic Chatbot

## About the Project
This project is a simple rule-based chatbot developed using Python as part of the CodeAlpha Python Programming Internship (Task 4).

The chatbot responds to predefined user inputs using keyword matching and displays appropriate replies.

## Features
- Responds to greetings such as hello, hi, and hey.
- Answers simple questions.
- Responds to thank-you messages.
- Provides basic help information.
- Uses random fallback responses for unrecognized messages.
- Ends the conversation when the user types bye, goodbye, or see you.

## Technologies Used
- Python
- Random module
- Conditional statements
- Functions
- While loops
- String handling
- User input and output

## How to Run
1. Install Python on your computer.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python chatbot.py
```

## Example Interaction
```text
Chatbot: Hi! I'm a simple chatbot. Type 'bye' anytime to exit.

You: hello
Chatbot: Hi there! How can I help you today?

You: how are you?
Chatbot: I'm fine, thanks! How about you?

You: bye
Chatbot: Goodbye! Have a great day!
```

## Learning Outcomes
- Understanding conditional statements.
- Creating and calling functions.
- Using loops for continuous interaction.
- Performing basic string processing.
- Implementing a rule-based conversational system.

## Limitations
This chatbot uses predefined responses and simple keyword matching. It does not use artificial intelligence or machine learning to understand conversations.
